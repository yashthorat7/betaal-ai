# Phase 7 — Styling

**Goal:** Make everything look stunning for judges. Apply design system across all platforms.

**Time estimate:** 4–6 hours
**Prerequisite:** Phase 6 complete (everything works functionally)

---

## Step 1: Design System

Define a unified visual language (one source of truth):
- Color palette (dark mode primary or light — team decides)
- Typography (1–2 Google Fonts)
- Spacing scale (4px base)
- Border radius, shadows
- Component patterns (cards, buttons, inputs)

Document in `vibecoding/design_system.md`.

---

## Step 2: Mobile App Styling

1. Apply color palette to all screens
2. Style monitoring ring with gradient colors
3. Style charts with branded colors
4. Add subtle animations (splash fade, ring fill)
5. Style onboarding with branded look
6. Style chat bubbles
7. Bottom nav bar icons + selected state

---

## Step 3: Website Styling

1. Apply Tailwind classes for color palette
2. Style landing page hero (gradient background, larger typography)
3. Style feature cards (hover effects, shadows)
4. Style dashboard charts and rings
5. Style navbar (active link, scroll behavior)
6. Add Framer Motion scroll reveals
7. Responsive polish (mobile, tablet breakpoints)

---

## Step 4: Extension Styling

1. Style popup (progress ring, clean layout)
2. Style blur overlay (glassmorphism effect)
3. Style warning banner
4. Style options page

---

## Step 5: Final Polish

1. Add real icons (replace emoji placeholders)
2. Add app logo / branding
3. Generate or add hero images for website
4. Final responsive testing
5. Performance check (load times)

---

## Step 6: Demo Rehearsal

Run through the exact demo script 3 times:
1. First run: identify bugs or visual issues
2. Second run: fix issues, time the demo
3. Third run: smooth final run, should be under 5 minutes

---

## Step 7: Update All Docs

- Final update to all `progress.md` files
- Screenshot key screens for documentation
