# Context . Betaal AI Website (`betaal_web`)

## Project Status
This is a **Phase 3** prototype (B&W layout, dummy data). 
We are using **Next.js 14**, **Tailwind CSS v4**, **shadcn/ui**, and **Zustand**.

## Key Components
- **Navbar & Footer** initialized in `components/`.
- **Firebase Client SDK** initialized in `lib/firebase.js`.
- **Dummy Data Server** initialized in `lib/dummy-data.js` (mimicking Part 2 seed data).

## Development Rules
- **Demo-first**: Build according to the demo script in `vibecoding/rules.md`.
- **B&W First**: No coloring/styling until Phase 7.
- **Dummy Data**: Use `lib/dummy-data.js` for all reports/charts.
- **Refactor aggressively**: Keep code concise.

## Running locally
- `npm run dev` starts the website on `localhost:3000`.
